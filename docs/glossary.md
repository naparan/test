# 用語集

| 用語 | 意味 |
| --- | --- |
| リポジトリ | 履歴つきのプロジェクトフォルダ |
| ローカル / リモート | 自分の PC のリポジトリ / GitHub 上のリポジトリ |
| ワークツリー | 編集中のファイル |
| ステージ | 次のコミットに入れる変更を置く場所 |
| コミット | 変更を記録したセーブポイント |
| origin | リモートにつける名前(慣習) |
| push / pull | 履歴を GitHub に送る / GitHub から取り込む |
| clone | リモートリポジトリをまるごとコピーする |
| ブランチ | 履歴の分かれ道 |
| main | 基本となるブランチ |
| マージ | ブランチを合流させる |
| コンフリクト | 同じ行が別々に変更されていて、自動でマージできない状態 |
| プルリクエスト (PR) | 変更を取り込んでもらうための提案 |
| レビュー | PR の内容を他の人が確認すること |
| Issue | やること・バグ・アイデアを書く場所 |
| GitHub Flow | Issue → ブランチ → PR → マージを繰り返す進め方 |
