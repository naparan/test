# はじめての Git / GitHub

Git と GitHub を**はじめて触る大学生**向けの教材です。
上から順番に読みながら手を動かせば、「自分のファイルを GitHub に置く」「Issue とプルリクエストを使って開発を進める」ところまでたどり着けます。

## この教材のゴール

- Git と GitHub の違いを説明できる
- 自分のパソコンでコミットを積み、GitHub に push できる
- ブランチを切って作業し、プルリクエストでマージできる
- Issue でやることを管理し、プルリクエストとつなげられる

## 進め方

- 各章の **🧪 やってみよう** は実際に手を動かすパートです。読むだけで終わらせず、必ずやってみてください。
- **💡 ポイント** は覚えておくと後で効いてくる話、**⚠️ 注意** はハマりやすいところです。
- コマンドは `$` のあとの部分を入力します(`$` 自体は入力しません)。

```console
$ git --version
git version 2.47.0
```

## 前提

- パソコンの基本操作(ファイル・フォルダの作成、ターミナルを開く)ができる
- プログラミング経験は不要です。教材の中ではテキストファイルしか使いません。

## 対応環境

Windows / macOS / Linux のどれでも進められます。OS によって手順が違うところは書き分けています。
